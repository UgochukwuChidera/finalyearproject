Help Center

Overview

DAPE (Document Analysis and Processing Engine) is an AI-powered pipeline designed to automate the extraction of data from handwritten and printed forms. It combines traditional computer vision techniques with advanced Large Language Models (LLMs) to achieve high accuracy and reliability.

Core Workflow

1. Configuration

Define your form's structure in the Configurations tab. You can use the "Discover" feature to automatically detect fields from a template image.

2. Upload

Upload scans or photos of filled forms. DAPE supports PNG, JPG, and TIFF formats. Multiple files can be uploaded at once for batch processing.

3. AI Processing

The engine aligns the form, detects ink (handwriting), and uses the selected AI model to extract data. It also validates results against your defined rules and dictionaries.

4. Review → Finalize → Export

Fields with low confidence or validation errors are flagged for review. Confirm and finalize the review to store verified values, then download JSON, CSV, or XLSX exports from the job view.

Model Settings

You can configure which AI model DAPE uses in the Model Settings page. We recommend openai/gpt-4o-mini for a balance of speed and cost-effectiveness.

API Key: You can set your OpenRouter API key directly in the settings or via the OPENROUTER_API_KEY environment variable in your .env file.

Advanced Concepts

Confidence Scores: DAPE calculates a "Final Confidence" (C_final) for every field based on AI logprobs and dictionary matching.
Status Flow: pending_review means unresolved fields remain; finalized means review was confirmed and stored; completed means no manual review was required.
Audit Stream: Every action and extraction is logged in the Audit Stream, providing a complete history of how your data was processed.
Evaluation: Use the Evaluation tab to see performance metrics if you have provided ground truth data for your forms.
